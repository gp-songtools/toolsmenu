## About page

`about.html` presents every tool and how they hand work to each other, with screenshots in `img/` (WebP, about 1600 px wide). Keep it in step when tools gain headline features or new hand-offs.

## Song spec

`songspec/spec-to-suno/` holds **Spec to Suno**: `index.html` (instructions for both options), `suno-from-spec.zip` (the Claude skill: one folder, `suno-from-spec/SKILL.md`; sha256 `a3507041529da258f8f428055bec0606ba90d6d58283aab4b488d23e5b1ecb74`; download only, never unzip it here) and `spec-to-suno.html.download`, the page itself, kept byte for byte as its author supplied it (sha256 `2efe2127428e3ea335cf9711988d0d3a5909c431fc1bf608204c779f7c143422`; never edit it). It is offered only as a download: the `.download` name makes GitHub Pages serve it as a file, never as a page, and the link's `download="spec-to-suno.html"` gives it its real name.

`songspec/templates/` holds blank song, cover and loop (sound) specs, generated by spec-to-suno.html's own template function, so they match its in-page downloads.

`songspec/` holds the song spec: one Markdown file per song that every tool reads and writes its own part of. See [songspec/README.md](songspec/README.md).

## Privacy & credits

`privacy.html` covers every tool: Cloudflare Web Analytics (on every page), what each tool sends where, and credits. Every tool links to it; update it when a tool changes what it sends, stores or credits.

## Adding a tool

Add an entry to the `TOOLS` array in `index.html` (and to the table above).

## Publishing

In this repo's **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`.
